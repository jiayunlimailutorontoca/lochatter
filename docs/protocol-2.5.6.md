# 2.5.6

2.5.6 仅修订 Android 客户端。不新增帧，不新增 `kind`，数据库 schema 仍为 9。服务端 `Version` 仍为 `2.3.0`。

Android `versionCode` 为 56，`versionName` 为 `2.5.6`。

整理模型的默认选项改为云端接口，并排在列表第一位。未自行选择过型号的安装，打开后即为云端接口。已经选定本机型号的安装保持原选择。

云端接口仍须由用户填写地址和模型名，密钥可留空。未填齐时不得开始整理，提示为「先填写云端接口」。本机三档 Qwen3 仍可改选，行为与 2.5.5 相同。通话录音在任何选项下都不得发送。
