# 协议 2.3.0

2.3.0 不增加消息 `kind`，不增加 WebSocket 帧。数据库 schema 仍为 9。

Android `versionCode` 为 40，`versionName` 为 `2.3.0`。服务端 `Version` 为 `2.3.0`。`GET /healthz` 的 `version` 返回该版本号。

## 通话

两名用户之间的通话先使用已下发的 STUN 与 TURN 地址建立媒体路径，不等待打洞成功。媒体路径仍为中继时，主叫约每 20 秒发起一次 ICE 重启。非中继候选配对成功后，媒体改走该路径。重启未成功时通话保持，并可由 TURN 重新接通。已经直连后不再周期性重启。ICE 恢复失败累计两次后，通话结束。

`deploy/turnserver.conf` 允许 TCP 中转分配。UDP 直连与 UDP 中转的优先级高于 TCP。中继端口仍为 UDP 49160–49200。

助手通话的信令与 `call.caption` 帧不在本版本变更范围内。

## 本机字幕与纪要

人类通话的字幕取自本机麦克风，由本机 SenseVoice 识别。识别结果不写入消息，也不发送 `call.caption`。云端转写不接收该路音频。识别模型未就绪时通话继续，界面提示模型未就绪，且不在通话中下载模型。本机不转写对方的声音。

通话纪要默认关闭。用户在设置中打开后，本机下载并运行 Gemma 3 1B（int4）。纪要只使用本机字幕。字幕、录音与纪要不提交给云端大模型。挂断后，用户可丢弃纪要，或将其作为一条普通加密文本发送。未接听、助手通话、设置为关或字幕为空时，不生成纪要。

## 网页

网页在该次页面的内存中解密后播放 `audio` 与 `video`。`image` 与 `album` 可放大查看。`file` 按解密后的文件名下载。`location`、`call` 与 `sticker` 仍显示为一行摘要。令牌与密钥环仍不写入浏览器存储。网页不提供通话，也不提供助手操作。

## 2.3.1

2.3.1 仅修订 Android 客户端。不新增帧，不新增 `kind`，数据库 schema 仍为 9。服务端 `Version` 仍为 `2.3.0`。`GET /healthz` 的 `version` 仍返回 `2.3.0`。

Android `versionCode` 为 41，`versionName` 为 `2.3.1`。

纪要模型须由设置中的「下载纪要模型」单独下载。打开「挂断后整理纪要」不得开始下载。模型文件未在本机就绪时，该开关保持关闭。通话进行中不得下载该模型。下载完成不得自动打开该开关。

## 2.3.2

2.3.2 仅修订 Android 客户端。不新增帧，不新增 `kind`，数据库 schema 仍为 9。服务端 `Version` 仍为 `2.3.0`。

Android `versionCode` 为 42，`versionName` 为 `2.3.2`。

纪要模型文件仍为 Gemma 3 1B int4。下载地址改为魔搭社区，不得再使用需要许可令牌的 Hugging Face 地址。

## 2.3.3

2.3.3 仅修订 Android 客户端。不新增帧，不新增 `kind`，数据库 schema 仍为 9。服务端 `Version` 仍为 `2.3.0`。

Android `versionCode` 为 43，`versionName` 为 `2.3.3`。

通话字幕仍只从本机麦克风生成，不得发送。读取录音缓冲区时不得调用 `ByteBuffer.array()`。该调用会在 Android 16 上令进程退出。直连重试与纪要下载地址保持 2.3.2 的行为。
