# 2.5.4

2.5.4 仅修订 Android 客户端。不新增帧，不新增 `kind`，数据库 schema 仍为 9。服务端 `Version` 仍为 `2.3.0`。

Android `versionCode` 为 54，`versionName` 为 `2.5.4`。

本机整理改由 MNN 3.6.1 在 GPU 上运行。可选权重为 Qwen3 0.6B、Qwen3 1.7B 与 Qwen3 4B，默认 Qwen3 1.7B。三档分别从魔搭 `MNN/Qwen3-0.6B-MNN`、`MNN/Qwen3-1.7B-MNN`、`MNN/Qwen3-4B-MNN` 下载。加载时须把 `backend_type` 写成 `opencl`。不得改走 CPU。不得再加载 Qualcomm GenieX，也不得使用 Omni 权重。

Qwen3 4B 在加载前须核对手机内存。内存不足 8 GB 时须拒绝加载，并提示改用 Qwen3 1.7B 或 Qwen3 0.6B。该拒绝发生在加载时，不阻止下载。

GPU 打不开时须把错误告诉用户。文案为「GPU 没有打开」，或运行库返回的说明。不得静默改走 CPU。

用户亦可改选「云端接口」。该选项不下载权重。地址须以 `http` 开头，模型名不得为空，密钥可留空。请求按 OpenAI 的对话补全格式发送，仅包含当前要整理的文字。用户未选择该选项时，对话与通话字幕不得离开手机。通话录音在任何选项下都不得发送。

下载仍只发生在设置里的「下载这个模型」。权重不得打进安装包。生成仍逐字显示，停止仍保留已写出的文字。
