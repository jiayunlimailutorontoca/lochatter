# 2.5.1

2.5.1 仅修订 Android 客户端。不新增帧，不新增 `kind`，数据库 schema 仍为 9。服务端 `Version` 仍为 `2.3.0`。

Android `versionCode` 为 51，`versionName` 为 `2.5.1`。

与对方的聊天页右上角不得再放置语音通话、视频通话或助手入口。这三项须放在输入栏的加号面板中。右上角只保留菜单，菜单项仍为搜索消息、后台运行设置、清空聊天记录与退出登录。

助手未启用时，加号面板不得出现助手一项。会话列表中的助手一行保持不变。主聊天隐藏助手消息时，未读仍记在会话列表，不得再依赖聊天页右上角的圆点。
