# 协议增量 1.8（相对 1.7）

服务器 1.8.0，schema 不变（7）。

## 1. 相册消息 `album`

`msg.send` 新 kind `album`。只有人能发，不能发给助手。正文规则和 `image` 一样：必须先 `POST /media`，`text` 是可选说明（两人之间端到端加密），最长与图片说明相同。
聊天里的普通图片和视频也会出现在「我们的相册」里；从相册页上传的照片用 `album`，视频仍用 `video`。

## 2. 共享键

仍走 `/shared`：

| key | 内容 |
|---|---|
| `pin` | 明文 `"1"` / `"0"`，两人的会话是否置顶 |
| `avatar` | 共享头像的 media id（值加密；文件本身是明文上传，两边都能拉） |
| `sign` | 签名，加密，最多 80 字 |

标为未读、消息提醒只在本机，不进协议。
