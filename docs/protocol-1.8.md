# 协议增量 1.8.0

相对 1.7.0。服务端版本 1.8.0。schema 保持为 7。

## 1. kind `album`

`msg.send` 增加 `kind` `album`。只有人类用户可以发送，且不能发给助手。正文规则与 `image` 相同：必须先 `POST /media`。`text` 为可选说明，在两名用户之间端到端加密，长度上限与图像说明相同。

聊天中的普通图像与视频也会出现在相册视图中。从相册页上传的照片使用 `album`。视频仍使用 `video`。

## 2. 共享键

仍使用 `/shared`。

| key | 内容 |
|---|---|
| `pin` | 明文 `"1"` 或 `"0"`。表示双人会话是否置顶 |
| `avatar` | 共享头像的媒体 `id`。值加密。文件本身明文上传，双方都可以下载 |
| `sign` | 签名，加密，最长 80 个字符 |

2.1 将头像与签名改为每名用户独立的键。上表中的 `avatar` 与 `sign` 自该版本起不再作为头像与签名使用。

标为未读与消息提醒只存在于本机，不进入协议。
