# 3.0.0

3.0.0 仅修订 Android 客户端。不新增帧，不新增 `kind`，数据库 schema 仍为 9。服务端 `Version` 仍为 `2.3.0`。

Android `versionCode` 为 57，`versionName` 为 `3.0.0`。

## 设置

设置首页只保留入口。每一项是名称加一行现状。点进去才是原来的开关、输入框或下一级页面。说明放在该页顶部，不超过两句。

首页顺序为：聊天、通话、加密与安全、本机能力、助手、账号、关于。原先散在首页的加密、通知、语音识别、通话纪要、安全、存储与诊断都收进这些入口，保存位置不变。下载模型的按钮仍只在「本机能力」里。打开某一项不得开始下载。

## 动画

页面打开时从右侧滑入，行程约为屏宽的八成，并带轻微缩放。返回时反向。位移使用同一条弹簧，松手后的回弹不中途改时长。首页三个分页改为短距离横向滑动并淡化。列表和设置分组第一次出现时短距升起。登录、锁屏和通话全屏仍不参与这层滑动。过渡帧使用目标页。过渡期间不得载入模型、解码大图或扫描整张消息表。

## 每日摘要

用户在「本机能力 → 每日摘要」打开之后，才按日整理两人的文字。使用的渠道与总结、润色、建议回复相同，即用户当前选中的整理模型。选的是云端接口，就把当天文字发到该接口；选的是本机型号，就在本机运行。未就绪时不运行，也不为此下载。

记录只留在这台手机，默认保留 90 天。不得发给 Hermes，不得自动发成一条聊天消息。通话录音不得发送。每个自然日最多调用一次模型。当天没有双方文字时不调用模型，次日补记「这天没有文字消息」。错过的一天不补跑模型。只在应用处于前台且当前没有通话时运行。

每天的结果为固定四行：日期、聊了什么、心情、可记住的事。心情只允许「平稳」「开心」「担心」「生气」「说不准」。可记住的事最多三条，且须能在当天原文里找到。

## 本版不做

助手的工具清单和固定格式回复本版不实现，留待另行讨论。手机仍不发起、不接听助手通话。
