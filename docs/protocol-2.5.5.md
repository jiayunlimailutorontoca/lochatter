# 2.5.5

2.5.5 仅修订 Android 客户端。不新增帧，不新增 `kind`，数据库 schema 仍为 9。服务端 `Version` 仍为 `2.3.0`。

Android `versionCode` 为 55，`versionName` 为 `2.5.5`。

本机整理模型不得在应用启动时加载。用户发起总结、润色、建议回复或总结摘要时，若该权重尚未留在内存中，须先载入，并在界面写明正在载入以及型号。载入完成后须保留该实例。同一进程内，同一型号再次整理不得重新载入，界面须改写「正在整理…」。

换型号时须卸掉已载入的实例。加载失败或内存不足导致加载失败时，亦须卸掉。系统报告内存偏低时，不得因此卸掉已载入的实例。

云端接口不载入本机权重。等待时须写明正在把文字发到云端接口。设置中的整理模型一行须标明当前本机模型是否已在内存中。
