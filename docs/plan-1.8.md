# lochatter 1.8 计划：交互微信化（二期）

写于 1.7.0 发布时（2026-09-23）。一期（1.7）做完了长按菜单 / 多选 / 撤回 / 转发、按住说话（上滑取消、右上滑转文字）、「+」面板与等高面板、首页三 Tab 与会话列表 / 草稿、5 分钟时间戳、双击大字、查看器下滑关闭与长按菜单、语音红点与时长宽度、屏幕共享沉浸模式、高德瓦片。按用户要求，主题预设和助手页公众号化没有做。

二期仍是单人顺序开发，每项独立可发。

| 序 | 内容 | 做法 | 预计 | 验收 |
|---|---|---|---|---|
| 1 | 拍摄：「+」里加「拍摄」 | CameraX（`camera-camera2` + `camera-view`）：照片和 ≤ 60 秒短视频，拍完进现有发送预览（可编辑、原图、阅后即焚） | 3 天 | 拍照 2 秒内进预览；视频有时长圈 |
| 2 | 多图发送带「原图」开关与说明 | `SendPreviewDialog` 支持多图横滑、统一原图开关、一段说明文字 | 1 天 | 9 张一次发出，顺序不乱 |
| 3 | 通话悬浮窗 / 画中画 / 锁屏接听 | 系统 PiP 已有；补应用内悬浮小窗（拖动、点回）、来电全屏通知 `setFullScreenIntent` + `setShowWhenLocked` 锁屏直接接听 | 3 天 | 锁屏来电不解锁能接；切出去看微信通话不断 |
| 4 | 聊天记录搜索页按类型 | 搜索页加 Tab：全部 / 图片 / 文件 / 链接 / 位置 / 日期跳转 | 2 天 | 搜「上海」能过滤出位置消息 |
| 5 | 消息置顶 / 标为未读 / 提醒 | 会话列表长按：置顶、标未读；消息长按「提醒」= 定时通知自己 | 2 天 | 列表顶部有置顶条 |
| 6 | 收藏页分类 | 收藏按图片 / 语音 / 位置 / 文件 / 文字分栏，长按转发 | 1 天 | 分栏计数正确 |
| 7 | 语音条微信化收尾 | 听筒模式灰条提示、长按语音「转文字」缓存显示、连播提示音 | 1 天 | 贴耳后列表顶部出现「听筒模式」 |
| 8 | 对方资料卡 | 点头像进资料页：头像（可换）、签名、安全码、纪念日、共同相册入口 | 2 天 | 头像两端同步 |
| 9 | 「我们的相册」 | 两人共同相册：按月分组、封面、上传自动进相册（服务端只存密文，走现有 media） | 3 天 | 上传后对方 3 秒内看到 |
| — | 真机回归（两台，一台 Android 12） | 一期 + 二期全过一遍 | 2 天 | 崩溃 0 |

合计约 3 周。协议变化：置顶 / 标未读放共享存储（`/shared`），相册用现有 media + 新 kind `album`（`docs/protocol-1.8.md` 到时写）。

之后（1.9）再做 `ChatRepository` 拆分和网页端雏形，2.0 做和助手打语音电话。
