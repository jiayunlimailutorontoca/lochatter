# 版本说明 1.8.0

紧接 1.7.0。schema 保持为 7。接口变更见 [protocol-1.8.md](protocol-1.8.md)。

- 附件面板提供拍摄。照片与不超过 60 秒的短视频进入既有的发送预览。
- 一次可发送多张图像，并带原图开关与一段说明。
- 通话可收为应用内小窗。锁屏来电使用全屏通知，无需先解锁即可接听。
- 检索可按全部、图像、文件、链接、位置过滤，并支持按日期跳转。
- 会话可以置顶。置顶状态存放在共享键 `pin`，双方一致。标为未读与消息提醒只存在于本机。
- 收藏按图像、语音、位置、文件、文本分类。
- 贴近耳朵时切换为听筒，并在列表中提示。语音消息可转写，结果缓存在该条消息上。
- 头像入口打开资料页，包含头像、签名、安全码、纪念日与相册入口。本版本的头像与签名仍是双方共用键。2.1 改为每名用户独立持有。
- 相册视图中，从相册页上传的照片使用 `kind` `album`。聊天中的普通图像与视频也出现在该视图中。

本版本未再修改高德瓦片。
