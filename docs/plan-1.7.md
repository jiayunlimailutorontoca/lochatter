# lochatter 1.7 计划：交互微信化（一期）

写于 1.6.0 开发中（2026-09-23）。目标一句话：**两个人打开 lochatter，手指的习惯和微信一样，不用学。**
1.6 把位置、文件、转文字补齐；1.7 不加大功能，专门改交互；1.8 二期收尾；2.0 才回到「和助手打电话」。

开发方式约定：从 1.7 起我一个人按顺序做，不再开多个 agent（省 token）。所以版本切小，每一条都能单独发。

## 0. 现状对照（哪些已经像微信、哪些还不像）

## 1. 首页：底部三 Tab（`HomeScreen`）

- **聊天**：会话列表两行——「对方名字」「助手名字」。每行：头像、最后一条预览（`[图片]`、`[语音] 6"`、`[位置] xx`、撤回提示）、时间、未读角标（对方红色数字，助手灰色数字 / 免打扰小铃铛）、对方在线 / 电量小字、`[草稿]` 红字。左滑：标为已读、免打扰。点进去就是现在的 `ChatScreen` / `BotScreen`。
- **相册**：现在的媒体库 `GalleryScreen` 直接搬来做 Tab（1.6 已加多选保存）。
- **我**：头像 + 名字 + 二维码换机入口；下面分组：外观、通知、助手、隐私（阅后即焚 / 定时销毁 / 密钥）、通话、备份、关于。就是 `SettingsScreen` 拆成微信「我 → 设置」的两级。
- 冷启动直接进「聊天 Tab」而不是聊天页；但有未读时通知点开仍直达聊天页。
- 草稿：离开聊天页时保存输入框文字（每会话一个键，`Prefs`），回来还在，会话列表显示 `[草稿]`。

## 2. 气泡长按：微信式弹出菜单 + 多选 + 撤回 + 转发

- 弹出层贴着气泡出现（在上方空间不够时出现在下方），横排图标 + 文字，最多两行，黑底白字圆角，带三角指示。项目按消息类型：
  - 文字：复制、转发、收藏、引用、多选、翻译（交给助手）、删除、撤回（自己的、2 分钟内）、编辑（自己的、已有）。
  - 图片 / 视频：转发、收藏、保存、编辑（图片）、引用、多选、删除、撤回。
  - 语音：转文字、收藏、引用、多选、删除、撤回。
  - 文件 / 位置 / 表情：转发、收藏、引用、多选、删除、撤回。
- **撤回**：新协议帧 `msg.recall`（服务端把原消息 kind 改为 `recall`，正文清空，保留时间和作者；对方端把气泡换成居中灰字「xx 撤回了一条消息」；自己端多一个「重新编辑」把原文塞回输入框）。2 分钟窗口服务端校验。老的「删除」保留在多选里。
- **转发**：目标只有两个——「对方」「助手」（还有「分享到其他 App」）。图片 / 文件转发复用 `mediaId`，不重传；密文消息转发前先解密再按目标重新加密。
- **多选**：进入后气泡左侧出现圆形勾选框，顶部栏「已选 n 项」，底部工具条：删除、转发（逐条）、收藏、保存（1.6 的批量保存）。
- 触发反馈：长按有震动（已有 `hapticFeedback`），弹出带 120 ms 缩放动画。

## 3. 输入区重做（`InputBar`）

- 左侧「语音 / 键盘」切换按钮。语音态下整条输入框变成「按住 说话」：按住出现录音浮层（音量波纹 + 计时），**上滑到取消区放手取消**，**滑到右边「转文字」区放手** → 调 1.6 的转文字（本机或服务器）→ 出现可编辑文本 → 「发送」或「发送原语音」。60 秒到自动发送并提示剩余 10 秒倒计时。
- 右侧「表情」「+」。「+」面板九宫格（一屏 8 个，可左右翻页）：相册、拍摄（1.8 先跳系统相机）、位置、文件、语音通话、视频通话、收藏、定时发送、阅后即焚、名片（发对方 / 助手的二维码，可选）。
- 表情面板：底部 Tab——最近、Emoji、表情包（ChineseBQB 按分类）、收藏（自定义），末尾「+」加自定义。面板高度 = 上一次键盘高度（`WindowInsets.ime` 记录到 `Prefs`），键盘 ↔ 面板切换时消息列表不跳。
- 输入���多行自动增高到 5 行；粘贴图片直接进入发送预览；`@` 弹出助手（主聊天里）。

## 4. 消息列表细节

- 「n 条新消息」浮标：滚上去时收到新消息，右下角出现圆角浮标，点回底部；进入聊天时如果未读 > 10，右上角显示「n 条未读」，点它跳到未读分割线。
- 时间分隔改为微信规则：两条消息间隔 > 5 分钟才显示时间；今天只显示时分，昨天「昨天 21:03」，一周内「周三 21:03」，更早显示日期。
- 双击文字气泡：全屏大字页（可选中复制部分文字，字号随手势缩放）。
- 标题栏第二行：「对方正在输入…」/「在线」/「x 分钟前在线」/「电量 12%」轮换。
- 已读：自己最后一条消息下方小字「已读」（微信没有，但两个人的 App 想留就留，设置里可关）。
- 消息进入动画（从下淡入 + 轻微上移），发送成功小勾。

## 5. 图片 / 视频查看器

- 下滑关闭（跟手位移 + 背景渐透明，回弹动画）。
- 长按：发送给对方 / 助手、收藏、保存图片、编辑、识别二维码（zxing 已在依赖里；识别到登录 / 换机码直接进对应流程）、搜一搜（交给助手）。
- 右上角「查看全部」：跳相册 Tab 并定位到当前图。
- 查看时如果是缩略图，右下角「原图 (2.3 M)」按钮，点了才拉原图（配合 1.5 的仅 Wi-Fi 设置）。
- 视频：双击暂停，左右滑进度，长按 2 倍速。

## 6. 语音

- 未听过的语音气泡右侧红点；听过消失（本地状态，`Db`）。
- 气泡宽度：`min + 时长 × 步长`，60 秒到最大宽度。
- 听筒模式：核对 `VoicePlayer` 的距离传感器逻辑（贴耳切听筒并降亮度、拿开切回扬声器且继续播）；设置里「听筒模式」开关。
- 播放中列表顶部出现「听筒模式 / 扬声器模式」灰条提示（微信的那个）。

## 7. 主题：微信绿预设

- `Theme.kt` 增加第 5 个主题「经典绿」：我方气泡 `#95EC69` 黑字，对方白底黑字，背景 `#EDEDED`，标题栏 `#EDEDED` 黑字，输入区 `#F7F7F7`；气泡尖角方案（现在的 round / square 之外加 tail）。默认不改，设置里一键切。

## 8. 助手页公众号化

- 底部菜单栏：像公众号那样一个「键盘 / 菜单」切换 + 三个一级菜单（可配置，来自现有共享快捷指令，支持二级弹出）。
- 卡片消息带按钮（`card` 正文里 `[按钮文字](cmd:...)` 语法 → 渲染成按钮，点了就发命令）。
- 回复中显示「…」打字气泡；长回复折叠「展开全文」；代码块可横向滚动 + 复制。

## 9. 顺序、工时、验收

一个人做，按下面顺序，每完成一项就能发一个 1.7.x 内测：

| 序 | 内容 | 预计 | 验收（对照微信） |
|---|---|---|---|
| 1 | 长按弹出菜单 + 多选 + 撤回��含服务端 `msg.recall`、e2e） | 4 天 | 长按 → 菜单贴气泡；撤回 2 分钟内两边同步变灰字；多选删 10 条 |
| 2 | 输入区：按住说话上滑取消 / 右滑转文字，「+」九宫格，等高面板 | 4 天 | 切表情 / 键盘列表不跳；滑到取消区放手无消息发出 |
| 3 | 首页三 Tab + 会话列表 + 草稿 | 4 天 | 冷启进列表；未读数正确；草稿保留 |
| 4 | 列表细节：新消息浮标、5 分钟时间规则、双击大字、标题栏状态 | 2 天 | 对照第 4 节逐条 |
| 5 | 查看器：下滑关闭、长按菜单、查看全部、原图按钮 | 2 天 | 下滑跟手；长按有 6 项 |
| 6 | 语音：红点、宽度、听筒核对 | 1 天 | 未听有红点；贴耳切听筒 |
| 7 | 经典绿主题 + 助手页菜单栏 + 卡片按钮 | 2 天 | 一键变绿；菜单二级弹出 |
| — | 真机回归（两台，其中一台 Android 12） | 2 天 | 崩溃 0；`导出诊断信息` 干净 |

合计约 3 周。协议变化只有 `msg.recall`（和转发复用 `mediaId` 的服务端校验），写进 `docs/protocol-1.7.md`。

## 10. 1.8（二期）预留

通话悬浮窗 / 画中画与锁屏接听（全屏通知 + `setShowWhenLocked`）；相机拍摄（CameraX，照片 + ≤ 60 秒短视频）；多图发送带原图开关和说明文字；聊天记录搜索页按类型 / 日期；消息置顶 / 标为未读 / 提醒；收藏页分类；对方头像与个性签名；「我们的相册」（两人共同相册，服务端只存密文）。

## 11. 不做的（和微信刻意不同）

朋友圈、公众号生态、支付、群聊、小程序；不��「消息已读」以外的任何对外可见状态；不引入第三方地图 SDK（1.6 的瓦片 + 高德 Web 服务足够）。
