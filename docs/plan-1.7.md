# 版本说明 1.7.0

发布日期 2026-09-23。schema 保持为 7。接口变更见 [protocol-1.7.md](protocol-1.7.md)。

本版本调整交互，不增加新的业务数据类型，撤回除外。

- 长按消息弹出操作：复制、转发、收藏、引用、多选、删除、撤回。文本撤回后，发送者可以重新编辑。撤回限于 2 分钟内、且只能撤回自己的消息。
- 多选后可以批量删除、转发、收藏与保存。
- 按住说话时，上滑取消，向右上滑动则先转写再发送。
- 首页为三个分页：聊天、相册、我。会话列表显示最后一条消息、未读数与草稿。草稿只保存在本机。
- 附件面板与键盘等高，切换时列表不跳动。
- 时间分隔约为 5 分钟。双击文本可放大。图像查看器支持下滑关闭。
- 未听的语音消息显示标记，气泡宽度随时长变化。
- 瓦片可切换为高德。服务端设置 `CHATTER_TILES=amap`。消息内的经纬度仍为 WGS-84，仅绘制时转换。

未交付：主题预设，以及助手页底栏。拍摄、多图发送、通话小窗列入 1.8.0。
