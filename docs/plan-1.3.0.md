# 版本说明 1.3.0

发布日期 2026-09-22。服务端 schema 7。Android `versionCode` 20。接口变更见 [protocol-1.3.md](protocol-1.3.md)。

## 1. 助手投递

1.3.0 之前，助手的同一条回复会入库三份。插件在 WebSocket 读循环内同步处理消息；处理阻塞时收不到 `msg.ack`，上游以新的 `id` 重发。1.3.0 将消息处理放到独立任务中，读循环不再阻塞。短时间内内容相同的重试复用同一个消息 `id`，服务端按 `id` 去重。上游的控制文本只写入日志，不写入聊天记录。

助手处于忙碌状态时，新消息并入当前轮次，不再以硬中断丢弃该输入。停止当前轮次使用显式的停止命令。

## 2. 同时交付的功能

- 助手页面提供一组命令与快捷指令。快捷指令存放在共享键 `quick`，值为明文。
- 发给助手的消息可以参与定时销毁。开关为 `bot_ttl`，默认开启。
- 表情库由 nginx 的 `/stickers/` 提供。自定义表情收藏使用共享键 `stickers`。
- 同时提供拍一拍、助手播报卡片、图像与视频的阅后即焚、纪念日、收藏、定时发送、链接预览，以及通话中的表情浮层。
- 电量通过 `active` 上报，对端通过 `presence` 接收。

加密备份不在 1.3.0 的交付范围内。
