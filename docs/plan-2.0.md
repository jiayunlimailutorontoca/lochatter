# 版本说明 2.0.0

本版本交付用户与助手之间的语音通话。双人通话的行为不变。接口见 [protocol-2.0.md](protocol-2.0.md)。

音频位于手机与运行助手的主机之间，传输为 WebRTC。聊天服务只转发信令，不转发音频。发给助手的 SDP 与 ICE 为明文，因为助手不持有双人会话密钥。音频由 DTLS-SRTP 保护。

助手侧使用 aiortc。人声按能量分段，整段提交到模型服务的 `/v1/audio/transcriptions`。文本进入既有助手流程，回复再经 `/v1/audio/speech` 返回通话。播放期间检测到人声则停止播放并取消本轮。转写失败时，同一段可以重试一次。未安装 aiortc 时，助手返回 `unavailable`，客户端改用按住说话。

接通后，助手先发送固定开场句。字幕使用 `call.caption`。模型标识由 `LOCHATTER_STT_MODEL` 与 `LOCHATTER_TTS_MODEL` 指定，必须是模型服务实际提供的标识。源码不内置模型名。

本版本的助手通话只有音频。`video` 为 true 的助手呼叫被拒绝。

登出时清除内存中的头像、签名、置顶状态与助手未读。下次登录只恢复当前账号的共享资料。头像能力在 1.8.0 已经存在，2.0.0 不另定义头像协议。

未纳入本版本：助手加入进行中的双人通话，将通话写入助手记忆，以及绕过工具直接调用实时语音模型。截至 2.2.0，助手加入双人通话仍未实现。
