# 2.5.0

2.5.0 仅修订 Android 客户端。不新增帧，不新增 `kind`，数据库 schema 仍为 9。服务端 `Version` 仍为 `2.3.0`。

Android `versionCode` 为 50，`versionName` 为 `2.5.0`。

本机整理、润色与建议回复改由 LiteRT-LM 运行 Qwen 的 `.litertlm` 文件。权重仍从魔搭社区下载，不得打进安装包。聊天、字幕、纪要与草稿不得上传。

可选型号如下。Qwen 没有正好 3B、且能被该运行时加载的文件，故默认取最接近的一档。

- Qwen3.5 4B，默认。约 2.6 GB。若手机内存不足 8 GB，则不得加载这一档，并提示改用更小的型号。
- Qwen3.5 2B。约 2.0 GB。
- Qwen3 1.7B。约 1 GB。

切换型号不得开始下载。下载仍只来自设置中该型号未就绪时的下载行。下载完成不得自动打开任何功能。模型未就绪时，「总结摘要」「总结聊天」「润色」「建议回复」只提示先下载。

生成过程须逐字显示已经写出的文字，并提供停止。用户停止后，已经写出的文字须保留。润色仍须用户确认后才替换草稿。建议回复仍须用户点选后才写入输入框。

上述文件只含文字解码器，不含视觉编码器。本版本不提供看图。推理只使用 CPU。模型可在当次使用后留在内存中；系统收回内存时须释放。
