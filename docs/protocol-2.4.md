# 协议增量 2.4

2.4.0 仅修订 Android 客户端。不新增帧，不新增 `kind`，数据库 schema 仍为 9。服务端 `Version` 仍为 `2.3.0`。

Android `versionCode` 为 49，`versionName` 为 `2.4.0`。

与对方的聊天页在输入栏放置「总结聊天」「润色」「建议回复」。这三项仍使用本机 Gemma，不得上传。润色在输入框已有草稿时才执行，确认后才替换草稿。建议回复须由用户点选后才写入输入框。输入栏不再提供把下一条消息发给助手的开关。

聊天页右上角保留语音通话、视频通话与助手入口。相册、收藏、纪念日、设置与消息定时销毁不在该菜单中重复出现，分别从「我」或设置进入。搜索、后台运行、清空聊天记录与退出登录仍留在该菜单。

手机不得发起助手通话，也不得接听 `bot` 为 true 的来电。两人之间的语音和视频通话不变。助手页仍可发送文字、语音消息，并朗读已经写好的回复。

页面进入与返回使用短距离滑入并配合淡入淡出。首页三个分页切换时交叉淡入。
